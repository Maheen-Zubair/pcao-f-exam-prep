# 📚 Vocabulary for Revision

> **Source:** [AI Prompting in 2026 — The AI Agent Factory](https://agentfactory.panaversity.org/docs/ai-prompting-2026)

These are the most important terms to remember from the course glossary.

## ⭐ The Most Important Vocabulary

| Term                        | Simple Meaning                                                                                       |
| --------------------------- | ---------------------------------------------------------------------------------------------------- |
| **Pretrained knowledge**    | What the AI learned during training, without looking anything up.                                    |
| **Knowledge cutoff**        | The point/date where the model's training information stops.                                         |
| **Web search**              | Fetching current information from live web pages.                                                    |
| **Deep research**           | A longer research process using many searches and sources to produce a structured report.            |
| **Slop**                    | AI output that sounds fluent but provides little real value.                                         |
| **Context window**          | Everything the model can see and use while generating one answer.                                    |
| **System prompt**           | Instructions placed into the AI's context by the product before the user interacts with it.          |
| **Stateless**               | The model itself keeps no memory between turns.                                                      |
| **Memory**                  | Information a product stores about the user and provides to the model in future chats.               |
| **Context rot**             | Decline in response quality when the context becomes too long or contains too many unrelated topics. |
| **Compacting**              | Replacing older conversation content with a shorter summary to make room for new context.            |
| **Projects**                | A workspace with persistent files and instructions that chats inside it can use.                     |
| **Reasoning**               | The model's internal working process before producing its final answer.                              |
| **Extended thinking**       | A mode that allows the model to spend longer reasoning before answering.                             |
| **Sycophancy**              | The tendency of AI to agree with what it thinks the user wants to hear.                              |
| **Rubric**                  | A set of specific criteria used to evaluate work.                                                    |
| **Brainstorm–iterate loop** | Context → options → feedback → repeat → expand one option.                                           |
| **Multimodal**              | Working with multiple types of input/output, such as text, images, audio, and files.                 |
| **Diffusion model**         | An image-generation model that starts with noise and gradually removes it to create an image.        |
| **Artifact**                | A working object created in a chat that can be edited, shared, or downloaded.                        |
| **Code execution**          | A tool that lets AI write and run a program on data.                                                 |
| **AI desktop apps**         | Apps that can work with files on your computer with your permission.                                 |
| **Jagged**                  | Uneven ability across different tasks; a model may be strong at one task and weak at another.        |
| **Model ladder**            | Different model levels from the same company, such as fast, medium, and heavy models.                |
| **Model family**            | All models belonging to the same company or model line.                                              |
| **A/B test**                | Sending the same prompt to multiple AI tools and comparing their answers.                            |
| **Agent**                   | AI that performs a multi-step job on its own instead of only replying to a user.                     |
| **Terminal**                | A text-based interface where commands are typed to control a computer.                               |
| **Codebase**                | All the files that make up a software project.                                                       |
| **SVG**                     | A text-based image format that can describe drawings and graphics.                                   |
| **CSV**                     | A plain-text spreadsheet format organized into rows and columns.                                     |
| **Version control**         | Software that tracks and saves previous versions of files.                                           |
| **Token**                   | A small chunk of text; model context limits are usually measured in tokens.                          |
| **Weights**                 | The trained numerical values inside a model.                                                         |
| **API**                     | A way for one program to communicate with or call another program/service.                           |
| **Arena**                   | A public model-comparison leaderboard where users compare model answers.                             |
| **NDA**                     | **Non-Disclosure Agreement** — an agreement to keep information private.                             |
