# 📚 Important Vocabulary — What AI Actually Is

**Source:** [What AI Actually Is — The AI Agent Factory](https://agentfactory.panaversity.org/docs/what-ai-actually-is-crash-course)

## ⭐ IMPORTANT VOCABULARY

| Term | Meaning |
|---|---|
| **Token** | Small chunk of text processed by the model. |
| **Tokenizer** | Breaks input into tokens. |
| **Stochastic** | Output is sampled from likely possibilities. |
| **Weights** | Frozen numbers learned during training. |
| **Parameters** | Another name for weights. |
| **Training** | Process that sets or adjusts weights. |
| **Pretraining** | First large-scale learning stage. |
| **Instruction tuning** | Training the model to follow instructions. |
| **RLHF** | Reinforcement Learning from Human Feedback. |
| **Inference** | Using the trained model. |
| **Knowledge cutoff** | Point after which training data is not included in the weights. |
| **Stateless** | Model has no memory of its own. |
| **Hallucination** | Fluent but false generated content. |
| **Context window** | Text/information currently available to the model. |
| **System prompt** | Product-provided instructions placed in context. |
| **Context rot** | Performance problems caused by overcrowded or poor context. |
| **Skills** | Instruction/reference folders loaded when relevant. |
| **Progressive disclosure** | Loading only the knowledge needed at the moment. |
| **Sycophancy** | Agreeing with what the user appears to want. |
| **Jagged frontier** | Uneven capability across tasks. |
| **Tool** | Action the model is allowed to call. |
| **Connector** | Tool connected to a real application. |
| **MCP** | Model Context Protocol. |
| **Agent** | Predictor + tools + repeated loop toward a goal. |
| **Reasoning** | More prediction/working before the final answer. |
| **API** | Direct programmatic link to a model. |
| **Artifact** | Substantial generated object such as a document, webpage, or tool. |

## 🔑 Quick Revision

### 🧠 Model Basics

- **Token** → Small chunk of text
- **Tokenizer** → Breaks input into tokens
- **Weights / Parameters** → Numbers learned during training
- **Training** → Process that sets or adjusts weights
- **Pretraining** → First large-scale learning stage
- **Instruction tuning** → Teaches the model to follow instructions
- **RLHF** → Reinforcement Learning from Human Feedback
- **Inference** → Using the trained model

### 📦 Context & Memory

- **Knowledge cutoff** → Point after which training data is not included in weights
- **Stateless** → Model has no memory of its own
- **Context window** → Information currently available to the model
- **System prompt** → Product-provided instructions placed in context
- **Context rot** → Performance problems from overcrowded or poor context
- **Skills** → Instruction/reference folders loaded when relevant
- **Progressive disclosure** → Load only the knowledge needed at the moment

### 🤖 AI Behavior & Capabilities

- **Stochastic** → Output is sampled from likely possibilities
- **Hallucination** → Fluent but false generated content
- **Sycophancy** → Agreeing with what the user appears to want
- **Jagged frontier** → Uneven capability across different tasks
- **Reasoning** → More prediction/working before the final answer

### 🛠️ Agents & Tools

- **Tool** → Action the model is allowed to call
- **Connector** → Tool connected to a real application
- **MCP** → Model Context Protocol
- **Agent** → Predictor + tools + repeated loop toward a goal
- **Artifact** → Substantial object generated by AI

### 💻 Development

- **API** → Direct programmatic link to a model
